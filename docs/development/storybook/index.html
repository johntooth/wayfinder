Wayfinder — Component Storybook

Visual reference for every UI component in the app. This revision moves the shell onto a warm paper canvas, replaces filled approval bubbles with quiet timeline events, and compresses the step rail into the header.

Figtree JetBrains Mono Accent #2f56d3 Canvas #faf9f7

Design Tokens

Core custom properties in shared.css. The neutral ramp is warm (paper, not grey) — surfaces sit on --bg, rails and insets on --bg2, pressed states and user bubbles on --bg3. White is reserved for cards that need to lift off the canvas.

Chat Interface

The feed is a single 760px column on the paper canvas. Three message shapes, deliberately unequal in weight: agent replies are plain prose with a small mark and no bubble; user messages are a quiet sand bubble on the right; events (approvals, edits, system actions) are timeline rows with a coloured initial. Approval traffic used to be full-width blue bubbles, which read louder than the agent's actual questions — these rows fix that.
